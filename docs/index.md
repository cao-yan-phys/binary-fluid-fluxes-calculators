# Binary Sound-Wave Flux Calculators

Numerical calculators for the time-averaged linear sound-wave fluxes generated by bound Keplerian binaries in homogeneous fluid backgrounds at rest in the binary center-of-mass frame. The supported media are a classical inviscid Newtonian barotropic fluid and a Schrödinger-Poisson quantum fluid.

The numerical calculators evaluate the harmonic sums with automatic convergence checks. They support CUDA acceleration through `numba.cuda` when available and can also run on the CPU.
